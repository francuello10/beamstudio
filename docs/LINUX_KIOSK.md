# Linux Kiosk / "Always On" Guide

This guide describes how to set up **BeamStudio** to run automatically when the computer turns on, acting as a permanent lighting controller dashboard.

## 1. Install the Application
First, install the `.deb` package generated by the build process.

```bash
sudo dpkg -i dist/beamstudio_1.0.0_amd64.deb
```
*(If you have dependency errors, run `sudo apt-get install -f` to fix them).*

## 2. Enable Auto-Login
For a dashboard, you want the computer to log in automatically without a password.
1.  Open **Settings** > **Users**.
2.  Unlock the settings and toggle **Automatic Login** to **ON**.

## 3. Configure Auto-Start (The "Dash" Mode)
To make BeamStudio start immediately after login:

### Option A: GUI Method (Easiest)
1.  Open "Startup Applications" from the Ubuntu menu.
2.  Click **Add**.
3.  **Name**: BeamStudio
4.  **Command**: `/opt/BeamStudio/beamstudio` (or just `beamstudio` if it's in the path).
5.  **Comment**: Start Lighting Controller.
6.  Click **Save**.

### Option B: Systemd Helper (Advanced)
If you want to ensure it restarts if it crashes (Kiosk style), create a systemd user service.

1.  Create the file `~/.config/systemd/user/beamstudio.service`:
    ```ini
    [Unit]
    Description=BeamStudio Kiosk
    After=graphical-session.target

    [Service]
    ExecStart=/opt/BeamStudio/beamstudio --no-sandbox
    Restart=always
    RestartSec=5

    [Install]
    WantedBy=default.target
    ```

2.  Enable it:
    ```bash
    systemctl --user enable beamstudio
    systemctl --user start beamstudio
    ```

## 4. Optional: Hide Standard Desktop Elements
To make it look like a dedicated appliance:
1.  **Auto-hide Dock**: Settings > Appearance > Auto-hide the Dock (ON).
2.  **Hide Top Bar** (Components): Install the "Hide Top Bar" Gnome extension.

Now, whenever you power on the machine, it will boot directly into BeamStudio.
